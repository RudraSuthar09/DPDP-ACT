DPDP Gateway Setup

Connect this computer to your DPDP workspace

The Gateway securely connects your computer and its approved data sources (databases, folders) to your DPDP workspace. Your data stays on this machine -- only metadata ever travels to DPDP.

This should take about two minutes. You will need the enrolment code shown in your DPDP dashboard under Data Sources → Connect Enterprise Gateway.

Connect workspace

Enter the URL of your DPDP workspace.

Pair this device

Paste the enrolment code shown in your DPDP dashboard. It is single-use and expires after a short time.

Verifying connection

This takes a few seconds.

  • ○ Gateway service running
  • ○ Enrollment confirmed by DPDP
  • ○ Backend connectivity established
✅

Gateway connected

Your Gateway is installed and running. It will start automatically with Windows, even before you sign in.
