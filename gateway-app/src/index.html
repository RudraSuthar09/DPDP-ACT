DPDP Gateway Setup

Connect this computer to your DPDP workspace

The Gateway securely connects your computer and its approved data sources (databases, folders) to your DPDP workspace. Your data stays on this machine -- only metadata ever travels to DPDP.

This should take about two minutes. You will need the server address and the enrolment code shown in your DPDP dashboard under Data Sources → Connect Enterprise Gateway.

Connect to DPDP

Enter the server address shown in your DPDP dashboard next to the enrolment code (Data Sources → Connect Enterprise Gateway). It is not always the address you use to open the dashboard.

Pair this device

Paste the enrolment code shown in your DPDP dashboard. It is single-use and expires after a short time.

Verifying connection

This usually takes a few seconds. If DPDP cannot be reached right away, the Gateway keeps trying for up to two minutes before reporting a problem.
